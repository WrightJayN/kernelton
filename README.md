# Kernelton

A browser game that teaches Operating Systems (CIT3002) from the ground up. The player runs a small town, and every town service is an Operating Systems concept in disguise.

## How to play

Open `index.html` in any modern browser. There is nothing to install and no build step. Progress is saved in the browser on that device.

- **Lens** (or the `L` key) shows the real Operating Systems term for every town word.
- **I know this** skips a puzzle and goes straight to its checkpoint.
- **Test out** inside a district clears the whole district with 4 of 5 correct.
- **Placement test** on the title screen starts you at the first district you did not pass.
- **Settings** has Expert mode, Revision mode, story, music and sound switches.

## What is in the game

- 10 worlds and 51 levels, one world per lecture week, following the CIT3002 syllabus.
- 13 practical levels with a simulated Linux terminal. Worlds 1 to 5 follow Practical sheets 1 to 5.
- 4 mock tests that mirror Theory Tests 1, 2 and 3 and the Lab Test.
- 228 checkpoint questions, each with a one line explanation.

## Project layout

| Path | Purpose |
| --- | --- |
| `index.html`, `css/style.css` | Page shell and styling |
| `js/engine.js` | Screens, level flow, puzzle types, saving, sound |
| `js/content/*.js` | All worlds, levels, puzzles and questions |
| `assets/*.svg` | Character portraits, generated by `tools/gen-art.js` |
| `tools/playtest.js` | Plays every level in a headless browser to check the answers |

## Adding or changing a level

Levels are plain data in `js/content/`. Write the correct answer first in every question, because the engine shuffles the options. Wrap paired wording as `[[town words|real term]]` and the engine shows the right one for the level's language layer.

After any change to the content, run the play-through. It needs Node.js and Playwright.

```bash
node tools/playtest.js
```
